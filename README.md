# RAGE POP-UP website

Ready for GitHub Pages. No installation or build required.

1. Extract this ZIP on your computer.
2. In a new GitHub repository, select Add file > Upload files.
3. Upload index.html, config.js, registration.js, README.md and the assets folder directly to the repository root. Do not upload the ZIP itself.
4. Commit the uploaded files.
5. Open repository Settings > Pages. Choose Deploy from a branch, branch main, folder / (root), then Save.
6. Wait for GitHub Pages to show the live URL. Open it and send one labelled test registration. Confirm the notification reaches the inbox associated with your Web3Forms key.

Web3Forms is configured. Its public access key is included intentionally. Do not add passwords or private API tokens.

This package includes the latest responsive layout and separate successful/already-registered messages. Repeat detection only works for registrations made in the same browser, after success. Clearing storage or using another device bypasses that check.

Google Sheets sync and an automatic central guest count are not connected. No attendee confirmation email is configured. The Web3Forms account's limits and domain restrictions still apply. Test the final GitHub Pages address before sharing it.
